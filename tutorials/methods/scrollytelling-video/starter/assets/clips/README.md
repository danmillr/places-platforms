# Clips folder

Put your `.mp4` video clips here. The starter references:

- `01_opening.mp4`
- `02_scene.mp4`
- `03_data.mp4`
- `04_close.mp4`

Rename to match your scene structure — just update `data-clip` in `index.html` if you rename them. See `../../README.md` for how to split a long source video into clips with `ffmpeg`.
