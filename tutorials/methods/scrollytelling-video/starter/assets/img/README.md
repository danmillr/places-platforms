# Overlay images

Put JPGs / PNGs / SVGs used in `left-panel` and `right-panel` overlays here.

The starter references `example.jpg`. Delete it and add your own; update the `src` in `index.html`.

**Sizing:** overlays cap image width at ~380px. Export at 2× the display width (~760px wide) for retina crispness. JPEG quality 78-85, or WebP for smaller files.
